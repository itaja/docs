Itaja abstracts away the complexity of integrating with individual mobile money networks. Instead of building and maintaining separate integrations for MTN, Orange, M-Pesa, Wave, and others, you connect once to Itaja and reach customers across 19+ countries through a single, consistent API. Each provider is identified by a short code that you include in your API requests to tell Itaja which network to use for a given customer or subscription.

## Using Provider Codes

When you create a customer or subscription through the Itaja API, you pass a `provider` field in the request body. This code tells Itaja which mobile money network to use when initiating payment collection and sending reminders. Make sure the provider code you supply matches the network your customer actually uses — an incorrect code will result in a failed payment attempt.

For example, to bill a customer in Senegal on Orange Money, you set `"provider": "orange_sn"` in your request. To bill a customer in Kenya on M-Pesa, you set `"provider": "mpesa_ke"`.

## Testing Providers

In sandbox mode, all provider codes work with test phone numbers — you don't need a real mobile money account to simulate payment flows. Use any phone number in the format specified in the [API reference](/api-reference/introduction) to trigger success, failure, or pending states and verify that your integration handles each outcome correctly before going live.
